# Docker

## Description
Projet consacré à **Docker**, une plateforme permettant de créer, déployer et exécuter des applications dans des conteneurs isolés.

## Objectifs
- Comprendre le fonctionnement des conteneurs
- Créer et utiliser des images Docker
- Manipuler les commandes Docker essentielles
- Conteneuriser une application

## Concepts clés
- Images
- Containers
- Dockerfile
- Volumes
- Ports & Networking

## Technologies
- Docker
- Linux
- CLI

## Exécution
```bash
docker build -t mon_image .
docker run mon_image
